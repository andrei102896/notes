-------*SUBJECT TAB ATTRIBUTES AND BEHAVIOR:*left click  ‘+’ at top left of dashboard to add a subject tab    *in the subject tab modal, left click to enter name for subject tab being added and left click 'OK'	-to add a subject tab requires text input even if it is a single letter	------------------------------------------------------------------------------POTENTIAL FUTURE UPDATE			-it would be advantageous to be able to add more than one subject tab at a time [this could be a future update]------------------------------------------------------------------------------*subject tabs:	-boxes will be one size equivalent to [3] alphabetical index boxes by default 	-type character limit of nine [8] 	-type in the color of white, using the font Fjallo One Regular, point size 24 and upper case only	*subject tabs are scrollable with middle mouse wheel and once scrolling has stopped the subject tabs will 'lock' to a full subject tab and not in between subject tabs	*when a new subject tab is added: 	-the added subject tab will be placed alphabetically into the subject tab 'stream'		-the added subject tab will be highlighted same as when user clicks on a subject tab to access it's notes 	-that subject tab will be positioned visibly in the subject tab stream**			**should there be enough subject tabs and subject tab being added does not start with a letter where the subject tab stream is		  currently, the subject tab stream would queue up so as to put the newly added subject tab visibly, allowing for user to add		  notes immediately*to rename a subject tab already on the dashboard:        -left double click subject tab on dashboard        -subject tab naming roll out reappears        -type in new name        -when done left click 'OK' ​*subject tabs populate alphabetically in descending order just under alphabetical index [AI]​*subject tabs cannot be reordered  ​*once a subject tab has been made it remains even if unpopulated with any notes*to delete a subject tab, click DELETE TAB via macro controls in dashboard header*after clicking DELETE TAB, a prompt [modal] will pop up saying:  THIS CANNOT BE UNDONE:  PROCEED?  YES  |  NO*if user clicks yes, the subject tab will be deleted, the subject tab stream will snap together filling the gap created by the now deleted subject tab*after deleting a subject tab no subject tabs will be selected and dashboard will display with no subject tabs highlighted and a modal in the dashboard area will read:			Select or create a subject tab to view, edit or add notes to.
