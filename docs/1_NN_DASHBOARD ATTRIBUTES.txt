NN [Notes For Net] Chrome browser extensionNN_DASHBOARD-------DASHBOARD:  ATTRIBUTES*NN icon in browser bar toggles minimize/ maximize [reveal/ conceal] of NN in browser window​*NN facilitates the saving and notating of webpages via links built into a sticky note like format housed under subject tabs acting as folders, each using the singular dashboard individually*subject tabs are created by left clicking '+' icon at the upper left corner of the dashboard*dashboard becomes scrollable as notes added demands*when a new note is added it populates to the top of the dashboard and THE DASHBOARD SCROLLS TO THE TOP revealing new note*when NN is maximized: 		-sits at right side of browser window 	-will be screen size/ resolution aware extending vertically from just under browser bar to top of task bar [MS] / dock [mac OS]	-taking up approximately 1/3 of the screens real estate horizontally right to left	-is unaffected when scrolling in browser window*when minimized slides off the right side of the browser window completely hidden*has macro controls to:        [DASHBOARD HEADER]   	- '+' [Add Subject Tab]		- ADD NOTE        - MIN MAX DELETE [This Tab Notes]        - DELETE TAB    	        *semi-opaque white background with blurring quality of browser window beneath it [if not possible, fully opaque off-white background] 	-------DASHBOARD: BEHAVIOR*after installing NN, and when NN is launched for the FIRST TIME on Chrome browser, dashboard will display devoid of subject tabs since none have been made and a message in the dashboard area will display:			Select or create a subject tab to view, edit or add notes to. *when duplicating an existing browser tab with NN maximized, NN will not display on the duplicated browser tab*when adding a new browser tab then launching NN on this new browser tab, dashboard will display with no subject tabs highlighted and a message in the dashboard area will display:			Select or create a subject tab to view, edit or add notes to.*while NN is launched; when the link or anchor function is being accessed via a note, NN will remain visible and not minimize*with NN maximized in a single browser tab and user interacts with NN in any way possible on that single browser tab, if user minimizes NN dashboard and then maximizes it, NN will remain temporarily persistent regarding the status of where the user left it visually; the subject tab they were on, notes expanded/ collapsed, scroll position, etc.*if user closes that browser tab, then temporary persistence is no longer applicable since temporary persistence is only applicable to a single browser tab session			​
